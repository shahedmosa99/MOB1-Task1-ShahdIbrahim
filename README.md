# MOB1 - Task 1

Five single-screen Android apps (Java + XML layouts), each with Light and Dark mode.

| # | App | Folder | Notes |
|---|-----|--------|-------|
| 1 | Birthday Card | [1-BirthdayCard](1-BirthdayCard) | Full-screen background image with greeting text |
| 2 | Task Done | [2-TaskDone](2-TaskDone) | Centered image and two lines of text |
| 3 | Quadrant | [3-Quadrant](3-Quadrant) | Screen split into four equal parts with `layout_weight` |
| 4 | Article | [4-Article](4-Article) | Banner image and long text inside a `ScrollView` |
| 5 | Business Card | [5-BusinessCard](5-BusinessCard) | Logo, name and title, contact rows with icons |

Each folder is a separate Android Studio project: open it with **File > Open**.

Dark mode: colors live in `res/values/colors.xml` (light) and `res/values-night/colors.xml` (dark).
